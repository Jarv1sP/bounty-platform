搭把手 Local v1.1.0

本版新增：个人工作台、团队成果墙、验收感谢、已验收成果的有帮助反馈、真实团队动态和算法团队任务分类。

完整本地应用：前端页面、Flask 后端、SQLite 数据库、启动脚本和离线依赖。
交付数据库为新建的专用演示库；不包含原工作目录的账号、密钥或任务。

已验证：
- 15 项服务端测试：完整任务流程、退回重交、任务归属、并发认领、并发验收只发一次勋章、输入与 CSRF 校验、数据库迁移、个人展示位权限和上限、首次入册不重播、重启会话与数据持久化、演示库初始化。
- 真实 Chromium 流程：两个账号登录、页面发布、认领、提交、退回、重交、验收、勋章发放和来源、展示位保存、真实委托墙、工作台、成果墙、反馈提交/取消及刷新持久化、关闭动效、系统减少动态效果及桌面/手机布局。
- 发布包已解压到含中文和空格的全新目录验证：用 Python -S 禁用系统第三方库后，包内依赖独立启动，15 项测试通过。
- ZIP 文件清单与 SHA-256 校验通过；数据库 integrity_check 与 foreign_key_check 通过；不含原账号、会话密钥、研究截图、静态模拟页面或平台专用二进制扩展。
- 从解压包实际启动 HTTP 服务，注册两名新用户并完成发布、认领、退回重交、验收、勋章与展示位；验证服务重启后会话/数据保留，以及运行中备份、独立目录恢复后登录与成果保留。

平台边界：
- 已在 Linux / Python 3.13 / Chromium 下执行验证。
- Windows 双击入口已提供；未在 Windows 原生 Python 上实机执行。
- 发布包依赖采用纯 Python，MarkupSafe 使用官方纯 Python 回退实现。
- 需要电脑预装 Python 3.10+，不含 Python 安装程序。
- 仅本机服务，无公网部署、收费、转账和通知服务。
- 成果为文字和链接，未实现文件附件上传、任务编辑/取消和管理员后台。
